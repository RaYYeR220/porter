# Requirements checklist

Each requirement on this checklist, and where to check it: in the code, on the live site, and in the Otari dashboard of the org running Porter. Pages are on https://porter-frontdesk.vercel.app. For what is live today, see [JUDGES.md](JUDGES.md#what-is-live).

## Repository

- Branch: `devs-wilding`.
- First commit where Otari came in: [`88418d5` Add Otari gateway client](https://github.com/RaYYeR220/porter/commit/88418d5ef15d8924f460dcff718e49bfcab4eb53) ([`lib/otari/client.ts`](lib/otari/client.ts), [`lib/otari/errors.ts`](lib/otari/errors.ts)).
- Everything runs on hosted otari.ai: `/api/v1` on the org's regional host, no self-hosted gateway.

| Requirement | Evidence |
| --- | --- |
| Uses open-weight models | Every model in the runtime path is open-weight: `deepseek/deepseek-v4.1-flash-1017`, `deepseek/deepseek-v4-flash-0731`, Qwen3 Coder 480B, GLM-5.3-Flash, `alibaba/qwen3guard-gen-8b`, `openai/gpt-oss-safeguard-120b`, `meta/llama-guard-4-12b`, `alibaba/qwen3-embedding-4b`, plus the fallbacks listed in the [README](README.md#open-weight-models-and-their-roles), among them `openai/gpt-oss-120b`. Code names routing policies, never a closed model id: [`lib/agent/roles.ts`](lib/agent/roles.ts), [`packages/porter-guard/src/protocol.ts`](packages/porter-guard/src/protocol.ts), [`lib/snapshot/embed.ts`](lib/snapshot/embed.ts). |
| Two or more open-weight models with different purposes | Triage (DeepSeek V4.1 Flash), tier-down (DeepSeek V4 Flash), repro (Qwen3 Coder), review (GLM-5.3-Flash), injection classifiers (Qwen3Guard, gpt-oss-safeguard), harm classifier (Llama Guard 4), duplicate search (Qwen3-Embedding). Site: each step of a run trace shows the model that served it; [run d1c674d7](https://porter-frontdesk.vercel.app/console/runs/d1c674d7-895d-4cf8-a89d-88acf41050cc) has triage, repro and review on three different models.
